# Check DEM

โปรแกรมหาวันที่เริ่มเก็บค่า Demurrage (**DEM.**) และวันรับตู้ (**REC.**) ของทุก B/L โดยคำนวณจาก **Freedays** และวันที่ **ATA** แล้วสร้างรายงาน Excel ที่มีสีแยกตามวัน พร้อมพิมพ์บนกระดาษ A4

## กติกาการคำนวณ

| ช่อง | วิธีคิด | ตัวอย่าง (ATA 27/09/2026) |
|---|---|---|
| **TOTAL** | เลขตัวหน้าของ Freedays + เลขตัวหน้าหลังคำว่า `Add` | `7/5 Add 7/9` → 7 + 7 = **14** |
| **DEM.** | ATA + TOTAL วัน | 27/09/2026 + 14 = **2026-10-11** |
| **REC.** | ATA + 3 วัน เฉพาะแถวที่มีคำว่า `TOS` (แถวอื่นเว้นว่าง) | `7/5 Add 7/9 TOS 3` → **30/09/2026** |

ตัวอย่างอื่น: `3/3 Add 2/11` → 5 วัน, `3/3 Add 9/4` → 12 วัน, `7/5 Add 14/2` → 21 วัน

## ไฟล์ต้นฉบับ (input)

ไฟล์ `.xls` หรือ `.xlsx` ที่แถวแรกเป็นหัวตาราง และต้องมีคอลัมน์ **Freedays** คอลัมน์อื่น เช่น `B/L No.`, `RECEIPT B/L` และ `Consignee` จะถูกคัดลอกไปที่รายงานตามเดิม

| Freedays | B/L No. | RECEIPT B/L | Consignee |
|---|---|---|---|
| 7/5 Add 7/9 TOS 3 | HASLC03260800809 | | DELTA DAIKI METAL (THAILAND) |
| 3/3 Add 2/11 | HASLC03260801573 | SUR | SUMITOMO RUBBER (THAILAND)CO.,LTD. |

## รายงานที่ได้ (output/Check DEM.xlsx)

- แถบหัวรายงาน **CHECK DEM** และแถวข้อมูล ต้นฉบับ | ATA | จำนวน B/L
- ตารางมีคอลัมน์ No. | REC. | TOTAL | Freedays | DEM. | B/L No. | RECEIPT B/L | Consignee
- **ช่อง DEM. และ Freedays ที่เป็นวันเดียวกันจะเป็นสีเดียวกัน** สีไล่จากวันแรกสุด (แดง) ไปวันหลังสุด (ฟ้า)
- แถวที่มี TOS จะเป็นตัวหนาสีแดง และช่อง REC. มีพื้นสีส้ม
- ช่อง RECEIPT B/L เป็นพื้นเหลือง ตัวแดง
- ถ้าอ่าน Freedays ไม่ได้ ช่อง DEM. จะเป็นพื้นแดงและขึ้นคำว่า `CHECK`
- ความกว้างของช่องปรับให้พอดีตัวอักษร ตรึงหัวตารางไว้ มีปุ่ม Filter และตั้งค่าพิมพ์ **A4 แนวตั้ง** พอดี 1 หน้ากว้าง

## ใช้งานผ่านเว็บ (ไม่ต้องติดตั้งอะไร)

เปิดที่ **https://rattanao.github.io/Check-dem/**

1. ลากไฟล์ Freedays มาวาง หรือคลิกเพื่อเลือกไฟล์
2. เลือกวันที่ ATA แล้วกด **คำนวณ**
3. ตารางบนหน้าจอจะแสดงสีตามวัน DEM. คลิกป้ายวันที่เพื่อซ่อนหรือแสดงวันนั้น และค้นหา B/L หรือ Consignee ได้
4. กด **ดาวน์โหลด Check DEM.xlsx** จะได้ไฟล์ Excel รูปแบบเดียวกับที่โปรแกรม Python สร้าง

ไฟล์ถูกประมวลผลในเบราว์เซอร์ของเครื่องที่ใช้อยู่เท่านั้น ไม่มีการอัปโหลดข้อมูลไปที่ใด ตัวเว็บคือไฟล์ [`index.html`](index.html)

## ติดตั้ง (สำหรับโปรแกรม Python)

ต้องมี Python 3.9 ขึ้นไป

```bash
pip install -r requirements.txt
```

## วิธีใช้

### แบบที่ 1: ดับเบิลคลิก (Windows)

1. วางไฟล์ต้นฉบับไว้ในโฟลเดอร์ `input`
2. ดับเบิลคลิก `run_check_dem.bat`
3. พิมพ์วันที่ ATA เช่น `27/09/2026` แล้วกด Enter
4. เปิดไฟล์ผลลัพธ์ `output/Check DEM.xlsx`

### แบบที่ 2: คำสั่ง

```bash
python check_dem.py input/DEM-KMGY.xls 27/09/2026
```

ถ้าต้องการกำหนดโฟลเดอร์ผลลัพธ์เอง ให้ใส่เป็นค่าที่ 3:

```bash
python check_dem.py input/DEM-KMGY.xls 27/09/2026 D:/reports
```

ถ้าไม่ใส่วันที่ ATA โปรแกรมจะถามตอนรัน
