Check DEM

หาวันเริ่มเก็บค่า Demurrage (DEM.) และวันรับตู้ (REC.) ของทุก B/L จาก Freedays กับวันที่เรือเข้า (ATA) แล้วออกรายงาน CHECK DEM.xlsx แบบใส่สีแยกตามวัน พร้อมพิมพ์ A4

SUR.xls (Freedays)+ ATA→ CHECK DEM.xlsx
ใช้งานออนไลน์ (ไม่ต้องติดตั้ง) ดาวน์โหลดโปรแกรม (ZIP) เปิดหน้า GitHub

Project by Ms. Rattana Mudlae · Position Import DOC.

ใช้งานออนไลน์

เปิดได้ทันทีจากเบราว์เซอร์ ไฟล์ถูกคำนวณในเครื่องที่ใช้อยู่เท่านั้น ไม่มีการอัปโหลดข้อมูลไปที่ใด

  1. กด "ใช้งานออนไลน์" ด้านบน แล้วลากไฟล์ Freedays (.xls / .xlsx) มาวาง หรือคลิกเพื่อเลือกไฟล์

  2. เลือกวันที่ ATA แล้วกด คำนวณ

    ตารางบนหน้าจอใส่สีตามวัน DEM. คลิกป้ายวันที่เพื่อซ่อนหรือแสดงวันนั้น และค้นหา B/L หรือ Consignee ได้

  3. กด "ดาวน์โหลด CHECK DEM.xlsx"

    ได้ไฟล์ Excel หน้าตาเดียวกับที่โปรแกรมในเครื่องสร้าง

ติดตั้งโปรแกรมในเครื่อง (ครั้งแรก)

ทำครั้งเดียวต่อเครื่อง ใช้ Windows ถ้าใช้แบบออนไลน์ด้านบนก็ไม่ต้องติดตั้งอะไรเลย

  1. ติดตั้ง Python 3 จาก python.org/downloads

    หน้าแรกของตัวติดตั้ง ติ๊ก ☑ Add python.exe to PATH ก่อนกด Install Now

  2. ดาวน์โหลดโปรแกรม กดปุ่ม "ดาวน์โหลดโปรแกรม (ZIP)" ด้านบน

    คลิกขวาที่ไฟล์ ZIP → Extract All แล้วเก็บโฟลเดอร์ไว้ที่ไหนก็ได้ เช่น Documents

  3. รันครั้งแรกต้องต่ออินเทอร์เน็ต

    โปรแกรมจะติดตั้งไลบรารีที่ต้องใช้ (pandas, openpyxl, xlrd) ให้เองอัตโนมัติ

ใช้งานในเครื่องทุกครั้ง

  1. วางไฟล์ Freedays ในโฟลเดอร์ input

    ฟอร์ม Excel มีได้หลายแบบ โปรแกรมหาหัวข้อที่ต้องใช้จากชื่อหัวข้อเอง ไม่ต้องจัดคอลัมน์ใหม่ (ดูหัวข้อที่อ่านด้านล่าง)

  2. ดับเบิลคลิก run_check_dem.bat แล้วพิมพ์วันที่ ATA เช่น 04/10/2026 กด Enter

    พิมพ์เป็น วัน/เดือน/ปี ค.ศ. เสมอ

  3. เปิดผลที่ output\CHECK DEM.xlsx

    หน้าจอดำจะบอกจำนวน B/L และจำนวนแถวที่อ่าน Freedays ไม่ได้ ไฟล์ตั้งค่าพิมพ์ A4 แนวตั้ง 1 หน้ากว้างไว้แล้ว

กติกาการคำนวณ

ช่องวิธีคิดตัวอย่าง (ATA 04/10/2026)
TOTALเลขตัวหน้าของ Freedays + เลขตัวหน้าหลังคำว่า Add3/3 Add 2/4 → 3 + 2 = 5
DEM.ATA + TOTAL วัน04/10/2026 + 5 = 09/10/2026
REC.ATA + 3 วัน เฉพาะแถวที่มีคำว่า TOS หรือเป็นตู้เย็น แถวอื่นเว้นว่าง7/5 Add 7/9 TOS 3 → 07/10/2026

ตู้เย็น: ถ้าช่อง TPSZ ขึ้นต้นด้วย R เช่น R40Hx1 ถือเป็น TOS 3 เสมอ เพราะต้องมีค่าไฟ โปรแกรมคิด REC. ให้เลยแม้ช่อง Freedays จะไม่ได้เขียน TOS

หัวข้อที่โปรแกรมอ่าน (ตามชื่อ ไม่สนตำแหน่ง)

  • Freedays (ต้องมี)
  • TPSZ
  • B/L No.
  • RECEIPT B/L
  • Consignee

ไม่นำมาใช้

  • หัวข้ออื่นทั้งหมด เช่น POL, STATUS
  • หัวตารางไม่จำเป็นต้องอยู่แถวแรก โปรแกรมหาแถวที่มีคำว่า Freedays เอง
  • รายงานออกมาเป็นฟอร์มเดิมเสมอ ไม่ว่าต้นฉบับจะเรียงคอลัมน์แบบไหน

อ่านรายงาน CHECK DEM.xlsx

หนึ่งแถวต่อหนึ่ง B/L แถวบนสุดบอกจำนวน B/L ชื่อไฟล์ต้นฉบับ และวันที่ ATA

ตัวอย่างประกอบเท่านั้น เลข B/L และชื่อบริษัทสมมติ · แถว 4 เป็นตู้เย็น (R40H) จึงมี REC. แม้ Freedays ไม่มีคำว่า TOS · แถว 3 ช่อง Freedays ว่าง จึงขึ้น CHECK

สีตามวัน DEM.ช่อง Freedays กับ DEM. วันเดียวกันสีเดียวกัน ไล่จากวันแรกสุด (แดง) ไปวันหลังสุด (ฟ้า)
ส้ม (ช่อง REC.)แถวที่มี TOS หรือเป็นตู้เย็น ต้องรับตู้/มีค่าไฟ
เหลือง (RECEIPT B/L)ประเภทการรับ B/L เช่น SUR / SWB ตัวแดง
แดง CHECK (ช่อง DEM.)อ่าน Freedays ไม่ได้ ต้องตรวจและคำนวณเอง

ใช้กับ Claude Code

สำหรับคนที่ใช้ Claude Code อยู่แล้ว ให้ Claude รันโปรแกรม สรุปผล และปรับกฎเพิ่มให้ได้

แตก ZIP แล้วเปิดหน้าจอดำ (cmd) ในโฟลเดอร์โปรแกรม พิมพ์คำสั่งนี้เพื่อติดตั้ง skill:

xcopy /E /I /Y skill\check-dem "%USERPROFILE%\.claude\skills\check-dem"
